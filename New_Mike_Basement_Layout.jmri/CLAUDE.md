## Project Overview

This is a JMRI (Java Model Railroad Interface) configuration repository for Mike Dean's basement HO-scale model railroad layout. The repository is version-controlled with git and stored at `~/JMRI/`. It contains multiple JMRI profiles, a shared roster, and Jython automation scripts. The working directory is the `New_Mike_Basement_Layout.jmri` profile.

## Repository Structure

The git repo root is `~/JMRI/`, one level above this `.jmri` profile directory. Key locations:

- **`New_Mike_Basement_Layout.jmri/`** — Active profile (this directory). Uses NCE command station (simulator mode available). The main layout panel file is `December2024Settings.xml` (~5900 lines).
- **`Basement_Revised_2024.jmri/`** — Revised layout profile with updated track plan (active development since April 2025). Latest panel: `May2025Settings.xml`.
- **`My_NCE_Simulator.jmri/`** — Simulator profile for working without hardware.
- **`roster/`** — Shared locomotive roster (~45 entries). All profiles reference this single roster location via `jmri-jmrit-roster.directory=home:JMRI/` in profile.properties.
- **`jython/`** — Shared Jython scripts (~183 scripts) for automation, including custom and stock JMRI scripts.
- **`roster.xml`** / **`roster.csv`** — Master roster index files at repo root.
- **`blockvalues.xml`** — Persisted block occupancy values.
- **`dispatcheroptions.xml`** — Dispatcher configuration (signal mast based, HO scale).

## JMRI Panel/Settings XML Structure

The main settings XML files (e.g., `December2024Settings.xml`) are JMRI's serialized layout configuration. They contain, in order:
1. **Sensors** — NCE sensors (`NS*`) organized by layout area: North (NS86-105), South (NS80-85, NS128-137), East (NS112-125), West (NS106-107), Mountain (NS109). Internal sensors (`IS*`) for logic.
2. **Turnouts** — NCE turnouts (`NT*`), e.g., NT504.
3. **Signal Heads / Signal Masts** — 12 signal heads and 12 signal masts for CTC-style signaling.
4. **Blocks** — 93 blocks for occupancy detection.
5. **Sections** — 28 sections for Dispatcher/warrant routing.
6. **Layout Editor panel** — Named "Mike Dean's Basement Layout" with track geometry, turnout positions, and visual elements.

## Layout Geography

The layout is divided into named areas: **North** (zones 1-10, tracks 1-6, bypass), **South** (zones 1-7, tracks 1-4), **East** (zones 1-13), **West** (NW and SW sub-areas), and **Mountain**. Naming conventions in sensors, blocks, and sections follow this geographic scheme.

## Profile Configuration

Each `.jmri` profile directory contains:
- `profile/profile.xml` — Connection config and startup actions (loads panel XML, starts WiThrottle server on port 12090, web server on port 12080, opens system console).
- `profile/profile.properties` — Preferences including roster path, web server settings, LogixNG options.
- `signal/WarrantPreferences.xml` — Speed map for warrants (N scale factor 160.0).
- `throttle/` — WiThrottle and throttle preferences.
- `backupPanels/` — Timestamped automatic backups of panel files.

## Working with JMRI XML Files

- Panel XML files are generated by JMRI — edit with care. Prefer making changes through the JMRI GUI when possible.
- When editing XML directly: preserve the XML schema references, maintain element ordering, and ensure system names follow JMRI conventions (prefix `N` for NCE, `I` for internal, followed by type letter: `S`=sensor, `T`=turnout, `B`=block).
- JMRI creates `.bak` files automatically; these are excluded by `.gitignore`.
- The `backupPanels/` directories contain automatic backups — useful for recovery but generally not committed.

## Git Conventions

- Single `master` branch, pushed to GitHub (`mdean77/JMRI`).
- Commit messages are informal, describing what changed in the layout configuration.
- `.gitignore` excludes `.bak` files, `.DS_Store`, and backup panel XMLs from `Mike_Basement_Layout/`.
